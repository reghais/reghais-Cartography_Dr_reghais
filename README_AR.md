# منصة الجيولوجيا العامة 1 — نسخة منقّحة

## سبب عدم ظهور الموقع في النسخة الأصلية

هذا مشروع React/Vite. ملف index.html الأصلي يستدعي src/main.jsx؛ هذا مصدر JSX وليس JavaScript جاهزاً للمتصفح. GitHub Pages يستضيف الملفات الثابتة ولا يبني مشروع Vite تلقائياً إذا اكتفيت برفع ملفات المصدر إلى فرع النشر. كذلك لم يتضمن المشروع إعداد نشر، وكانت المسارات الافتراضية تبدأ من جذر النطاق بدلاً من دعم مسار المستودع.

## النشر الموصى به — GitHub Actions

1. فك ضغط الحزمة على جهازك. ارفع **محتوياتها إلى جذر المستودع**، وليس الملف المضغوط نفسه أو مجلداً يحوي المشروع داخله.
2. يجب أن يظهر package.json وindex.html وvite.config.js في جذر المستودع، وأن يكون ملف .github/workflows/deploy.yml موجوداً. انتبه إلى الملفات والمجلدات المخفية عند الرفع.
3. هذه النسخة معدّة للفرع main. إذا كان الفرع اسمه master أو اسماً آخر، غيّر branches في ملف النشر، أو استخدم التشغيل اليدوي من Actions على الفرع الصحيح.
4. من المستودع افتح Settings → Pages. تحت Build and deployment اختر Source: GitHub Actions. يجب تفعيل Actions وأن تكون لديك صلاحية إعداد Pages.
5. من تبويب Actions شغّل Deploy academic website to GitHub Pages يدوياً إذا لم يبدأ تلقائياً. انتظر اكتمال مهمتَي build وdeploy بعلامة نجاح.
6. افتح رابط الموقع الذي يظهر في Settings → Pages أو في نتيجة النشر. رابط عرض الملفات على github.com ليس رابط الموقع المنشور.

**لا تختَر النشر من الفرع للمصدر غير المبني. لا ترفع ملف ZIP فقط وتنتظر أن يُعرض كموقع.**

## اختبار محلي على جهاز متصل بالإنترنت

يلزم Node.js إصدار 22 (أو إصدار مدعوم يحقق متطلبات المشروع) وnpm.

```bash
npm ci
npm run check
npm run build
npm run preview
```

افتح العنوان الذي يعرضه الأمر الأخير. لا تفتح index.html الأصلي مباشرة بالفأرة؛ استخدم الخادم المحلي أعلاه.

## بديل: النشر من فرع دون GitHub Actions

نفّذ npm ci ثم npm run build. انشر **محتويات dist فقط** إلى جذر فرع مخصص مثل gh-pages. في Settings → Pages اختر Deploy from a branch، ثم gh-pages و/(root). يجب رفع مجلد assets مع index.html، لا index.html وحده. لا تخلط هذه الطريقة مع نشر المصدر من main.

## أهم التصحيحات

- base: './' في Vite كي تعمل الموارد في مستودع مشروع أو على نطاق مستقل.
- إعداد بناء ونشر رسمي لـGitHub Pages، وإضافة .nojekyll وأيقونة محلية للموقع.
- تحميل CSS الخاص بـLeaflet وأيقونات العلامات ضمن البناء بدلاً من الاعتماد على CDN لأصولها.
- تصحيح قوالب عناوين OpenStreetMap وOpenTopoMap، وإعادة تمركز الخريطة عند تغيير الموقع.
- استخدام عنوان صادق للخريطة؛ ليست صوراً فضائية.
- استبدال رسالة «تم الإرسال» الوهمية بفتح مسودة mailto في برنامج البريد. الموقع الثابت لا يرسل الرسائل بنفسه. عنوان المستلم هو العنوان الوارد في النسخة الأصلية؛ أكّد صحته مع المؤسسة.
- حفظ القسم الحالي في hash ليستمر بعد تحديث الصفحة، ودعم الرجوع والتقدم، وحفظ تفضيل المظهر.
- إضافة رسالة خطأ بدلاً من شاشة بيضاء عند وقوع خطأ React، وتحسين الوصول بلوحة المفاتيح واللمس وتخطيط القراءة العربي.
- منع استبدال المسافة صفر بالعدد 1 في حاسبة الميل؛ تعرض القيم غير المعرّفة صراحة.
- بيان شروط علاقة السماكة e = L × sin(α): طبقة مستوية وسطح أفقي وعرض مكشاف أرضي مقاس عمودياً على المضرب؛ عدم استخدامها كحل عام للطبقات الأفقية والطيات والفوالق.
- تعديل سؤال قاعدة V؛ اتجاه رأس V ليس دليلاً مطلقاً على اتجاه ميل الطبقة.
- توضيح أن المقطع الطبوغرافي نموذج تخطيطي، وإزالة تحويل طول الرسم إلى كيلومترات دون معايرة موثّقة، وتصحيح توافق محور الارتفاع مع نقاط الرسم.
- إخراج المنشورات غير الموثّقة من واجهة العرض مع حفظ بياناتها الأصلية في PUBLICATIONS_TO_VERIFY.txt لاستكمالها بـDOI وروابط مباشرة.

## ما يلزم تأكيده أكاديمياً

احتفظت بالأسماء والانتماءات ورمز المقياس ومعلومات المؤسسة الواردة في المصدر، ولا يعني ذلك التحقق من صحتها رسمياً. يجب مراجعة بيانات الأستاذ والمؤسسة والبريد والهاتف والإحداثيات والحقوق قبل الإعلان عن الموقع بصفة رسمية. المواقع والإحداثيات تعليمية تقريبية، وليست إحداثيات مسح ميداني.

الخرائط الخارجية والخطوط وشعار المؤسسة تتطلب الإنترنت؛ تعذّر تحميلها لا يُفترض أن يمنع عرض النصوص. تحميل خرائط البلاطات يخضع لشروط مزوّديها. الواجهة ليست بديلاً عن خريطة جيولوجية مرجعية أو تقييم أكاديمي معتمد.

## حدود الاختبار في هذه المراجعة

تم فحص صياغة 19 ملف JavaScript/JSX وترابط الاستيراد المحلي باستخدام esbuild، وفحص إعداد النشر وروابط الموارد وقيم حسابية مرجعية. فحص الشيفرة لا يساوي اختباراً شاملاً لسلوك الموقع.

تعذّر npm ci بسبب ENOTFOUND عند الاتصال بـregistry.npmjs.org في بيئة المراجعة. لذلك **لم يُنجز بناء إنتاج كامل، أو اختبار وظائف في متصفح، أو فحص بصري كامل**، ولم يُنشر الموقع إلى مستودعك. لا تحتوي الحزمة على dist جاهز، ولا على node_modules. مهمة build في GitHub Actions هي اختبار القبول التالي؛ إذا فشلت، راجع أول رسالة خطأ في سجلها.
